# Statement on tools and AI use

We built the project on MongoDB Atlas (free M0 cluster) using the Data Explorer shell, the Aggregation Pipeline Builder and mongosh, and we stored all code, outputs and exports in a GitHub repository. We used an AI assistant (Lovable) to speed up drafting: it proposed the vendor data, the structure of the scripts, the pages used for screenshots, and a first version of the report and slides. We did not take its output on trust — every query was executed against a real MongoDB 8 database from an empty state, every number in the report was copied from the recorded outputs, and we checked the less common features (`arrayFilters`, `$merge`, `$jsonSchema`, covered queries in `explain`) against the official MongoDB documentation. Where the first suggestion was wrong or weak we changed it ourselves, for example rounding prices after the 10 % rise, making the random orders reproducible with a seed, and archiving orphaned orders instead of silently deleting them. Each team member can explain and modify the queries without the assistant.
